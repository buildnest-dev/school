## Acceptance criteria (§24) — frontend view

- _Rollover previewable, auditable, recoverable; must not overwrite closed years_ — preview and audit panel exist; **auditability, recovery and read-only archiving are backend guarantees** and the UI says execution requires backend authorisation.
- _Carry-forward dues link to originating year_ — not shown yet (ledger shows one year).
- _Promotion/detention/reshuffle support exceptions and authorised confirmation_ — exceptions, capacity and typed confirmation: yes; bulk execution: backend.
- _Certificates use approved templates, signatories, unique ids, auditable_ — preview wording only; the UI states numbers/signatures come from the backend.
- _Holiday/function calendars support audience targeting, reminders, emergency changes_ — display with audience labels only.
- _Parents only access authorised children; staff only what they need_ — UI shows only `childIds` from the session and role-filtered screens; **enforcement is backend**.
- _AI content stays a draft until approved_ — no AI features exist.
- _Integrations show accurate status_ — yes (status page: "Not connected").
